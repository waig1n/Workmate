Workmate is an open-source AI Agent platform for enterprise teams, combining RBAC + Scope governance, managed tools and knowledge, a file workspace, scheduled automation, and distributed execution with horizontal Worker scaling. These guides cover its capabilities, operation, and technical contracts.
