# 文档

[English](../en/README.md) | [简体中文](../zh-CN/README.md)

Workmate 是面向企业团队的开源 AI Agent 工作平台，整合 RBAC + Scope 权限治理、受管工具与知识、文件工作空间、定时自动化，以及支持多 Worker 横向扩展的分布式执行能力。本文档说明产品能力、使用方式和技术契约。
