# 使用指南

[English](../en/user-guide.md) | [简体中文](../zh-CN/user-guide.md)

Workmate 将智能体、工具和文件整合到同一个工作台。选择智能体、描述目标，再根据需要确认关键操作，即可查看答复和下载工作成果。

## 开始一次任务

1. 在工作台选择有权使用的智能体（Agent），也可以创建个人智能体。
2. 选择可用模型，输入任务目标；需要处理资料时添加附件。
3. 发送消息后创建会话。执行期间可在“执行活动”中查看工具调用，在主面板查看答复和成果。

例如，可以让智能体整理上传的资料、分析表格，或生成报告。所选智能体需要具备对应工具和文件处理能力；具体能力由管理员配置或授权。

同一会话中的任务按顺序执行，忙时新任务进入队列。会话支持搜索、重命名和删除；有任务运行时需先等待结束或停止任务，才能删除会话。

## 选择和管理智能体

个人智能体归本人所有。组织和部门智能体的创建、编辑、共享与删除取决于相应范围的权限。智能体的管理权限、运行权限，以及其 Skill、MCP 和知识库的使用权限分别检查。权限配置见[管理与安全](administration.md)。

模型列表由平台配置决定，并受智能体的可用范围限制。上传的附件会作为当前会话的工作文件供智能体使用。

## 审批与停止

发送任务前选择审批模式。任务创建后按该模式执行；需要确认时，审批卡片会展示工具、参数和可选操作。核对后再批准或拒绝。续跑时系统会重新检查当前权限。

“自动执行”（Full Access）仍受智能体的禁止规则和平台管理操作的强制确认约束。

点击停止后，任务进入停止处理流程，待执行和资源清理完成后更新最终状态。请以页面显示的任务状态为准；停止请求已受理时，外部工具可能仍在结束执行。

## 查看与下载成果

成果面板集中展示智能体交付的文件。文本、代码、结构化数据、图片和 PDF 等常见格式支持预览，其他格式可下载。下载需要当前账号具有访问权限；HTML 预览在隔离环境中展示。

编写智能体或 Skill 时，可通过 `present_files` 声明要交付的文件。默认交付模式还会识别 `output/` 目录中的文件变化；严格模式仅交付显式声明的文件。未交付的工作文件能否在故障后恢复，取决于[文件检查点配置](runtime.md)。

## 处理资源不可用

Skill、MCP 或知识库被停用、撤销授权，或超出智能体的可用范围时，系统可能拒绝新任务。查看资源诊断，修正绑定或联系管理员恢复授权后再试。已有会话记录仍可保留，但不会因此保留已撤销的执行权限。

## 设置定时任务

选择智能体、填写任务目标，并设置一次性、每天或每周计划及所在时区。计划支持暂停、恢复和查看执行历史。每次触发都会创建独立会话，并检查当前账号与资源权限。

定时任务无人值守运行，遇到必须人工确认的操作会拒绝执行。配置了渠道绑定后，结果可发送到本人绑定的 IM 私聊；通知失败可单独重试，无需重跑任务。配置步骤见[集成指南](integrations.md)。

同一用户与智能体的长期记忆可以跨会话使用，因此新建会话并不清除长期记忆。
